# Research papers: practical length targets

Practical starting points for a first research-paper draft. Check journal's requirements before submission, but first submission usually more relaxed.

## Quick targets

| Item | Starting target | 
| :--- | :--- | 
| Abstract | **<150 words** | 
| Main text | **3,000–4,000 words** (2,500 for shorter types) | 
| Main figures + tables | **4–6 combined** | 
| Methods, legends, references and supplementary material | As necessary | 

## Main text breakdown

| Section | 2,500 words | 3,000 words | 4,000 words |
| :--- | ---: | ---: | ---: |
| Introduction | 400 | 500 | 600 |
| Results | 1,400 | 1,700 | 2,400 |
| Discussion | 700 | 800 | 1,000 |
| **Total** | **2,500** | **3,000** | **4,000** |

## Sources

| Journal / research format | Journal text guidance (words) | Main figures + tables |
| :--- | :--- | :--- |
| [Nature](https://www.nature.com/nature/for-authors/formatting-guide) | **2,500 / 4,300** | **4 / 5–6 items** |
| [Nature Genetics](https://www.nature.com/ng/content) — Article / Analysis | **≤4,000 / ≤3,000 body** | **≤8 / ≤6** |
| [Nature Biotechnology](https://www.nature.com/nbt/content) — Article/Resource | **≤3,000 body** | **≤6** |
| [Nature Methods](https://www.nature.com/nmeth/content) — Article/Resource/Analysis | **3,000 body**; up to 5,000 | **≤6** |
| [Nature Cell Biology](https://www.nature.com/ncb/content) — Article / Resource | **≤5,000 body** | **5–8 / 6–8 main figures** |
| [Nature Communications](https://www.nature.com/ncomms/submit/article) — Article | Ideally **≤5,000 body** | **≤10** |
| [Cell](https://www.cell.com/cell/information-for-authors/article-types) — Research/Resource/Theory | **<7,000** | **≤7** |
| [Molecular Cell](https://www.cell.com/molecular-cell/information-for-authors/article-types) — Article/Resource | **≤7,000** | **≤7** |
| [Science](https://www.science.org/content/page/science-information-authors) — Research Article | **≤3,000 body** | **3–5** |
| [Science Advances](https://www.science.org/content/page/science-advances-information-authors) | **≤15,000** | **≤10** |
| [The EMBO Journal](https://link.springer.com/journal/44318/submission-guidelines) | No strict format limitations | **up to 10 main figures** |
